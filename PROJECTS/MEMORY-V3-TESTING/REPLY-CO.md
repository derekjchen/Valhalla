## 1. Memory V3 架构细节

### 四维分层架构

```
┌─────────────────────────────────────────────────────────┐
│  L3 偏好层 (Preference Layer)                           │
│  - 用户偏好的动态演化                                    │
│  - changes 数组追踪变化                                  │
│  - 三种类型: reinforce / override / decay               │
├─────────────────────────────────────────────────────────┤
│  L2 场景层 (Scene Layer)                                │
│  - 场景分类 (工作/个人/学习/娱乐)                         │
│  - 上下文快照                                           │
│  - 场景切换追踪                                         │
├─────────────────────────────────────────────────────────┤
│  L1 语义层 (Semantic Layer)                             │
│  - 实体提取 (人/地点/组织/技术)                          │
│  - 关系图谱                                             │
│  - 向量存储 (语义搜索)                                   │
├─────────────────────────────────────────────────────────┤
│  L0 原子层 (Atomic Layer)                               │
│  - 原始对话记录                                         │
│  - 时序索引                                             │
│  - 不可变存储                                           │
└─────────────────────────────────────────────────────────┘
```

### changes 数组格式

```json
{
  "preference_id": "pref_coffee",
  "topic": "coffee",
  "content": "喜欢拿铁",
  "sentiment": "positive",
  "confidence": 0.9,
  "changes": [
    {
      "type": "override",
      "old_value": "喜欢美式",
      "new_value": "喜欢拿铁",
      "reason": "美式太苦",
      "timestamp": "2026-03-17T14:00:00+08:00"
    }
  ]
}
```

### 三种变化类型

| 类型 | 触发条件 | 示例 |
|------|----------|------|
| **reinforce** | 相同偏好重复出现 | 连续 3 次说喜欢 Python |
| **override** | 相反偏好出现 | 之前说喜欢 Python，现在说改用 Node.js |
| **decay** | 长时间未提及 | 某偏好 30 天未出现，置信度下降 |

## 4. AB 测试方法

### 评估指标

| 维度 | 权重 | 测量方法 |
|------|------|----------|
| **准确率** | 30% | 关键信息是否正确 |
| **完整率** | 25% | 细节是否完整 |
| **关联能力** | 20% | 跨场景/时间关联 |
| **演化理解** | 15% | 偏好变化追踪 |
| **响应速度** | 10% | 检索延迟 |

### 成功标准

**V3 相比 V2:**
- 准确率提升 >= 10%
- 完整率提升 >= 20%
- 关联能力提升 >= 30%
